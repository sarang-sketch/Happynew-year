# 🎆 Happy New Year 2026 - From Sarang

A cinematic New Year celebration website with personalized fireworks!

## 🚀 Features

- **Personalized Experience**: Enter any name to see it displayed in fireworks
- **Cinematic Animation**: Child character lights a rocket that flies into the sky
- **Interactive Fireworks**: Canvas-based firework animations
- **Sound Effects**: Firecracker sounds and celebration audio
- **Mobile Responsive**: Works on all devices
- **GitHub Pages Ready**: 100% static, no backend required

## 🎬 Experience Flow

1. User enters their name
2. Child character appears and lights a firecracker
3. Rocket launches into the sky
4. User's name appears in fireworks
5. "Happy New Year 2026 From Sarang" message displays
6. Grand finale with continuous fireworks

## 🌐 Deployment

### GitHub Pages
1. Create a new repository
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select "Deploy from a branch" > "main"
5. Your site will be available at: `https://username.github.io/repository-name`

### Local Testing
Simply open `index.html` in any modern web browser.

## 🎵 Audio Files

The website uses embedded audio data for basic sounds. For better audio quality, you can replace the data URLs in `script.js` with actual audio files in the `/assets/` folder:

- `cracker.mp3` - Firecracker lighting sound
- `launch.mp3` - Rocket launch sound  
- `cheer.mp3` - Crowd cheering "Happy New Year!"
- `music.mp3` - Background celebration music

## 🎨 Customization

- **Colors**: Edit CSS color variables in `style.css`
- **Message**: Change "FROM SARANG" in `index.html` and `script.js`
- **Timing**: Adjust animation delays in `script.js`
- **Child Character**: Modify CSS in `.child` classes
